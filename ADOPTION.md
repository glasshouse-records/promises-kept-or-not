# Adoption ledger

The mission is not a clean dataset. It is a dataset **the world uses** to hold
large financial institutions to their own words. So this file tracks the only
metric that measures the mission: *who used it, for what.*

We track quality obsessively (`glasshouse metrics`, every detector's scorecard).
Until this file has entries, none of that has served the mission yet.

## How to record a use

Add a row. Anything counts: a citation, an article, a board pack, a class, a
regulator filing, a fork, a bug report that improved the record.

## If you used Glasshouse

Please tell us — it is the only feedback loop that tells this project what to
build next, and it costs you one line:

- open an issue titled `used: <who you are>`, or
- cite the dataset DOI and let us know.

Corrections are the most valuable kind of use. If a figure is wrong, the record
should change: open an issue with the table, the row, and the primary-source
link. Provenance is the product; being corrected in public is the point.
